# PGY 學員月評核（護理長／總醫師 → 一般內科 PGY1、PGY2）

與 CR 總醫師月評核（`index.html`、`Dashboard.html`）同一套模式，但資料放在**另一份試算表**，兩邊互不影響。

| 檔案 | 用途 |
|---|---|
| `pgy.html` | 問卷：護理長或 CR 一次評完當月 3–4 位 PGY |
| `PGY-Dashboard.html` | 儀表板（需密碼） |
| `gas/PGY評核_Code.gs` | Google Apps Script 後端 |

## 安裝

1. 新建一份 Google 試算表 → 擴充功能 → Apps Script，貼上 `gas/PGY評核_Code.gs`，執行一次 `setup`。
2. 到「設定」分頁填入：B1 評核開放日（預設 20）、B2 強制評核月份（平常留空）、B3 儀表板密碼、B4 管理者密碼。
3. 部署 → 網頁應用程式（執行身分：我；存取：所有人），把 `…/exec` 網址貼到 `pgy.html` 與 `PGY-Dashboard.html` 的 `CONFIG.GAS_URL`。

`GAS_URL` 留空時兩個頁面都是展示模式（問卷只顯示送出內容，儀表板用虛構範例資料）。

## 每月操作

- 打開 `pgy.html` → 右上角「管理者登入」（B4 密碼）→「＋ 新增月份」→ 輸入當月學員姓名並選 PGY1／PGY2 → 儲存。
- 把 `pgy.html` 連結給護理長與 CR。可加 `?role=護理長` 或 `?role=總醫師` 預選身分。
- 評核月份：每月 20 日（含）以後評「本月」，之前評「上個月」；也可用上方月份切換補評。

## 資料格式

「回覆」分頁一位學員一列：`時間戳記, 批次編號, 評核月份, 受評學員, 學員職別, 評估者姓名, 評估者身分, 狀態, 10 題分數, 表現優良之處, 建議加強之處`。
`狀態` 為「已評核」或「未共事」（評核者勾選略過）。同一評估者對同一學員重複送出時，儀表板只採計最新一次。
